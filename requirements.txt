# Union of every package required by the four pipeline modules.
# Mirrors the union of the four modules' _REQUIRED_PKGS, which each module
# auto-installs at import time if they are missing.  verify_docs.py check 7
# holds the two lists to each other.
#
# `spacecost` holds Stage 3's reference tables, which used to live in
# modules/transportation.py, and the recorded fuel quotes Stage 3 prices from.
# `spacevalue` is Stage 2's pricing, which used to be modules/mineral_value.py:
# Stage 2 installs its published price releases and re-exports its tables, and
# Stage 4 imports its cargo valuation (`spacevalue.cargo`, calc 1.33.0 on).
# Neither is on PyPI yet, so each is pinned to a TAGGED git ref; an untagged
# URL would change what a fresh install gets without anything here moving.
# Their table sizes are not spelled here: the stage banners print them.
#
# Stage 1 installs no package.  It downloads a pinned, published build of the
# asteroid catalog -- data, not code -- from the AsteroidCatalog repository's
# releases; the pin is `CatalogConfig.catalog_release` in modules/catalog.py.
# Stage 2 likewise downloads its prices; that pin is
# `MineralValueConfig.price_release` in modules/mineral_value.py.
#
# yfinance is not here: no stage fetches a live price by default any more.
# Asking for live quotes (`use_yfinance`) needs `pip install yfinance`.
requests
pandas
numpy
tqdm

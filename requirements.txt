# Union of every package required by the four pipeline modules.
# Mirrors the union of the four modules' _REQUIRED_PKGS, which each module
# auto-installs at import time if they are missing.  verify_docs.py check 7
# holds the two lists to each other.
#
# `spacecost` holds Stage 3's reference tables, which used to live in
# modules/transportation.py, and Stage 2's delivery chains.  It is not on PyPI
# yet, so it is pinned to a TAGGED git ref; an untagged URL would change what a
# fresh install gets without anything here moving.  Its table sizes are not
# spelled here: the Stage 3 banner prints them.
#
# Stage 1 installs no package.  It downloads a pinned, published build of the
# asteroid catalog -- data, not code -- from the AsteroidCatalog repository's
# releases; the pin is `CatalogConfig.catalog_release` in modules/catalog.py.
